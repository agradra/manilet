# Nexus App

**에이전트 통합 관리 TUI 프로그램**

`nexus_app`은 여러 에이전트를 실시간으로 모니터링하고 제어할 수 있는 TUI 애플리케이션입니다.
각 에이전트의 구동 상태, 실시간 로그 등을 하나의 대시보드에서 효율적으로 관리하며 디스코드 알람 및 프로세스 관리 등을 지원합니다.

## 설치
```bash
pip install "manilet-nexus-app @ git+https://github.com/agradra/manilet.git#subdirectory=nexus_app"
```
> [빠른 시작](../README.md#빠른-시작)을 이미 진행하였다면 넘어갑니다.

## 시작 명령어

터미널에 아래 명령어를 입력하여 앱을 실행합니다.
```bash
nexus
```
