# Nexus App 가이드

Nexus App의 초기 설정부터 주요 기능 사용 방법까지 안내합니다.

## 1. 초기 설정 (비밀번호 및 DB)

Nexus App은 중요한 설정(디스코드 웹훅, 지갑 정보 등)을 안전하게 관리하기 위해 내장된 암호화 데이터베이스(CryptoDB)를 사용합니다.

앱을 최초로 실행(`nexus`)하면 비밀번호를 설정하는 프롬프트가 나타납니다.
* **비밀번호 생성**: 앱 데이터 암호화에 사용될 비밀번호를 2회 입력하여 생성합니다.
* **비밀번호 검증**: 이후 앱을 재실행할 때마다 이전에 설정한 비밀번호를 입력해야 앱에 진입할 수 있습니다.

> ⚠️ **주의**: 설정한 비밀번호를 분실할 경우 저장된 모든 설정 데이터는 **절대 복구할 수 없습니다.** 반드시 안전한 곳에 보관하거나 뇌에 박아넣으십시오.

## 2. 화면 구성 및 주요 기능

앱은 크게 세 개의 탭(**Home**, **Agent**, **Wallet**)으로 구성되어 있으며, 상단 탭을 마우스로 클릭하거나 키보드 `Tab` 키를 통해 전환할 포커스를 맞춘 후 `←`, `→` 키를 눌러 전환할 수 있습니다.

### Home 탭 (시스템 모니터링 및 설정)
시스템 전반의 상태를 확인하고 앱의 기본 환경 설정을 구성합니다.
* **Discord 설정**: `Status`, `Log`, `Test` 채널용 디스코드 웹훅 URL을 UI 입력란에 직접 입력하여 연동합니다. (입력 즉시 암호화되어 안전하게 자동 저장됩니다.) `Mode` 라디오 버튼을 통해 현재 발송 모드를 변경할 수도 있습니다.
* **시스템 로그**: 디스코드 연동 실패, 에러 등 앱 자체에서 발생하는 이벤트가 실시간으로 표시됩니다.
* **성능 모니터**: 앱이 현재 사용 중인 시스템 자원(CPU, RAM) 및 관련 프로세스 정보를 확인합니다.
* **로그 저장 경로 설정**: 시스템 로그 파일과 에이전트 로그 파일이 저장될 폴더 경로를 지정할 수 있습니다. (기본값: 운영체제 기본 다운로드 폴더)

### Agent 탭 (에이전트 제어)
작성한 봇(에이전트)들을 개별적으로 모니터링하고 제어합니다.
* **에이전트 목록**: 지정된 폴더 경로에 있는 에이전트 스크립트(`.py`) 목록을 표시합니다.
  * 하단의 **Agents directory path** 입력창을 통해 에이전트 파일들이 위치한 폴더를 변경할 수 있습니다.
  * 상단 검색창 및 상태별 정렬 토글 기능(우측 스위치)을 지원합니다.

* **VENV 경로 설정**: 에이전트 실행에 사용될 파이썬 가상환경(venv) 경로를 지정할 수 있습니다.

### Wallet 탭 (지갑 관리)
* **개발중**: 향후 에이전트에서 사용할 지갑 시크릿 키 및 API 키 등을 암호화하여 관리하는 기능이 추가될 예정입니다.

## 3. 유용한 단축키 및 종료

* `F1`: 현재 화면에서 사용 가능한 단축키 모음(Help Panel) 팝업을 열거나 닫습니다.
* `Ctrl + G`: 포커스 되어있는 Pane을 최대화합니다. (`esc`를 누르면 다시 원래 크기로 돌아옵니다.)
* `Ctrl + Q`: 앱을 종료합니다.
* `Ctrl + P`: 상세 설정창을 호출합니다.
